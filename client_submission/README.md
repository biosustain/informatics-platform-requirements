# Client submissions

Answers submitted from the questionnaire site land here, one YAML file per submission:

```
client_submission/<template-id>/<YYYY-MM-DDTHHMM>Z-<project>-<random>.yaml
```

Files are written by the submission relay (`relay/worker.js`); don't rename them by hand if you
want them to keep sorting by date. Open them in the site under **Submissions**, or load a
downloaded file with **Open an answers file**.

> If this repository is public, everything in this folder is public. See the main README,
> "Privacy of submissions".
